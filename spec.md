# Спецификация: Video Trimmer (мгновенная обрезка видео)

## Цель
Загрузить одно видео, ползунками выбрать, какие части оставить, сохранить результат. Без монтажа, эффектов и клипмейкерства. Обрезка должна быть мгновенной.

## Границы (версия 0.1)
Входит: открытие файла, предпросмотр, выбор одного или нескольких фрагментов для сохранения, быстрая обрезка без перекодирования, точная обрезка с перекодированием, консольный запуск.
Не входит: эффекты, переходы, текст, музыка, несколько исходных видео, таймлайн-монтаж.

## Решения
- Python 3.10+, PySide6 (интерфейс и предпросмотр), ffmpeg/ffprobe (обрезка), pytest.
- Режим `fast` (по умолчанию): `-c copy`, без перекодирования, мгновенно; границы прилипают к ближайшим ключевым кадрам (неточность до долей секунды или нескольких секунд, зависит от видео).
- Режим `precise`: перекодирование libx264 (crf 18) + aac; точность до кадра, медленнее.
- Несколько фрагментов склеиваются в один файл в заданном порядке.
- Языки интерфейса: en (по умолчанию), ru, uk. README, комментарии, коммиты: английский.
- Метка авторства: уточнить у владельца позже (в коде не добавляется).

## Контракт ядра (`src/video_trimmer/core.py`) — единый для всех исполнителей
```
class TrimError(Exception)            # понятное сообщение для пользователя

@dataclass(frozen=True)
class VideoInfo: duration: float; width: int; height: int; has_audio: bool; has_video: bool

probe(path: str | Path) -> VideoInfo
keyframes(path: str | Path) -> list[float]            # времена ключевых кадров видеодорожки, по возрастанию
snap_to_keyframe(path, t: float, direction: str = "nearest") -> float   # direction: "nearest"|"before"|"after"
validate_ranges(ranges: list[tuple[float, float]], duration: float) -> list[tuple[float, float]]
default_output_path(src: str | Path) -> Path           # <папка>/<имя>_trimmed<расширение>, без перезаписи (добавляет _2, _3...)
trim(src, ranges, dst, mode: str = "fast", progress: Callable[[float], None] | None = None) -> Path
```
Правила:
- `validate_ranges`: каждая пара start < end, 0 <= start, end <= duration (допуск 0.001), пары не пересекаются; возвращает отсортированный список; иначе `TrimError`. Пустой список: ошибка.
- `trim`: проверяет существование src, что dst != src, что режим допустим; не перезаписывает чужие файлы без явного разрешения (dst уже существует: `TrimError`); при ошибке ffmpeg временные файлы удаляются, dst не остаётся; `progress` вызывается со значениями 0.0..1.0, последний вызов 1.0.
- Результат `fast`: длительность близка к сумме фрагментов (допуск: расстояние до ключевых кадров); результат `precise`: длительность равна сумме фрагментов с допуском 0.1 с на фрагмент.
- Аудио и видео сохраняются; файл только с аудио или только с видео тоже допустим.

## Консольный запуск (`python -m video_trimmer.cli`)
`python -m video_trimmer.cli INPUT OUTPUT --range START-END [--range ...] [--mode fast|precise]`
Время: секунды (`12.5`) или `мм:сс` / `чч:мм:сс`. Код выхода 0 при успехе, 1 при `TrimError` (сообщение в stderr).

## Интерфейс (`src/video_trimmer/ui/`, запуск `python -m video_trimmer`)
- Окно: область предпросмотра (QMediaPlayer + QVideoWidget), кнопка открытия файла (и перетаскивание файла в окно), Play/Pause, ползунок позиции.
- Диапазонный ползунок (две ручки: начало и конец) на всю длительность; под ним поля времени начала и конца, кнопки «взять текущую позицию как начало/конец».
- Список фрагментов: «Добавить фрагмент», «Удалить»; по умолчанию один фрагмент на весь файл.
- Переключатель режима: Быстро (без перекодирования) / Точно (с перекодированием).
- Кнопка «Сохранить»: диалог выбора пути (по умолчанию `default_output_path`), обрезка в фоновом потоке, индикатор прогресса, сообщение об успехе или понятная ошибка.
- Переключатель языка en/ru/uk; строки в отдельном модуле `i18n.py`.
- Интерфейс вызывает только публичный контракт ядра. Тяжёлые вызовы не блокируют окно.

## Критерии готовности
1. Все тесты зелёные (`pytest`), реально запущены, результат показан.
2. Реальная обрезка тестового ролика обоими режимами даёт файл, который открывает ffprobe, с ожидаемой длительностью.
3. Интерфейс запускается без ошибок в режиме `QT_QPA_PLATFORM=offscreen`, ключевые действия покрыты тестами.
4. Нельзя менять: контракт ядра выше без согласования с оркестратором.

## Разделение работ
- Тестировщик: `tests/` для ядра и консоли (до кода). Тестовые видео генерируются ffmpeg в фикстуре (`testsrc`, `sine`, ключевой кадр каждую секунду).
- Исполнитель UI: `src/video_trimmer/ui/`, `i18n.py`, `__main__.py`, тесты интерфейса `tests/test_ui.py`.
- Исполнитель ядра: `core.py`, `cli.py`; пишет код, пока тесты тестировщика не станут зелёными.

# Версия 0.2 — изменения (заменяют противоречащие места выше)

## Решения владельца
1. **Отдельные файлы.** Каждый фрагмент сохраняется отдельным файлом. Склейка в один файл интерфейсом больше не используется (функция `trim` остаётся в ядре для консоли и обратной совместимости).
2. **Перекрытия и повторы разрешены.** Каждый фрагмент вырезается из исходного видео независимо.
3. **Предпросмотр при выборе границ.** Пока пользователь тянет ручку «начало», окно показывает кадр начала; пока тянет «конец», показывает кадр конца. Один экран предпросмотра переходит на ручку, которую тянут. То же при правке полей времени и кнопках «взять текущую позицию».
4. **Звук.** Воспроизведение звука, кнопка Mute и ползунок громкости.
5. **Стиль «жидкое стекло» (liquid glass / glassmorphism).** Эталон: `/mnt/user-data/uploads/b5fafa10-image.png` (полупрозрачные матовые панели, сильно скруглённые кнопки-«таблетки», мягкие тени, светлая кайма). Две темы с переключателем в окне: светлая сине-серая и тёмно-фиолетовая. Кнопки хорошо видны, у них есть состояния (обычная, наведение, нажатие, недоступна).

## Дополнение контракта ядра (`core.py`)
```
validate_segments(ranges, duration) -> list[tuple[float, float]]
segment_output_paths(src, count, out_dir=None) -> list[Path]
trim_each(src, ranges, out_dir, mode="fast", progress=None) -> list[Path]
```
Правила:
- `validate_segments`: каждая пара start < end, 0 <= start, end <= duration (допуск 0.001); перекрытия и повторы разрешены; порядок сохраняется как задан; пустой список: `TrimError`.
- `segment_output_paths`: имена `<имя>_part1<расш>`, `<имя>_part2<расш>` ... в `out_dir` (по умолчанию папка исходника). Если хотя бы один файл набора уже существует, весь набор получает числовой суффикс к имени: `<имя>_2_part1<расш>`, затем `_3_...`. Файлы не создаются, существующие не перезаписываются.
- `trim_each`: проверяет src, режим и фрагменты; создаёт `out_dir` при отсутствии; каждый фрагмент вырезается из исходного файла независимо (не из других результатов); `progress` в диапазоне 0..1 по всем фрагментам, последний вызов 1.0; при ошибке любого фрагмента все файлы, созданные этим вызовом, удаляются и поднимается `TrimError`; возвращает список путей в порядке фрагментов. Режимы `fast` и `precise` как раньше.

## Консоль
Добавляется флаг `--separate`: `OUTPUT` трактуется как папка, каждый `--range` сохраняется отдельным файлом (перекрытия разрешены), печатаются пути всех файлов. Без флага поведение прежнее.

## Интерфейс (изменения)
- Сохранение: диалог выбора папки (по умолчанию папка исходного видео), затем `core.trim_each` в фоновом потоке; сообщение «сохранено N файлов» с папкой.
- «Добавить фрагмент» всегда доступно: новый фрагмент копирует выбранный. Удалять можно любой, кроме последнего.
- Перекрытия при редактировании не считаются ошибкой.
- Интерфейс использует `probe`, `validate_segments`, `trim_each`, `TrimError`, `VideoInfo` (и больше не `validate_ranges`, `trim`).
- Новые строки в `i18n.py` для en/ru/uk (одинаковые наборы ключей).
- Тема: модуль `ui/theme.py` со стилями (QSS) для двух тем; выбранная тема запоминается между запусками (QSettings).

## Критерии готовности v0.2
Все тесты зелёные и реально запущены; проверка ядра на реальном видео с перекрывающимися фрагментами в обоих режимах; интерфейс собирается и делает снимок в обеих темах (`QT_QPA_PLATFORM=offscreen`).

## Разделение работ v0.2
- Агент ядра: `src/video_trimmer/core.py`, `cli.py`, `tests/test_core.py`, `tests/test_cli.py`, `tests/conftest.py` (тесты до кода).
- Агент интерфейса: `src/video_trimmer/ui/`, `i18n.py`, `__main__.py`, `tests/test_ui.py`.
- Оркестратор: `spec.md`, `README.md`, слияние веток, проверка, pull request.

# Версия 0.2.1 — исправление интерфейса (замечания владельца с Windows, развёрнутое окно)

Замечания: на экране Windows элементы перекрывают друг друга (видео перекрывает панели с ползунками и звуком, поля Start/End наезжают друг на друга); при другом размере окна часть интерфейса не видна и работать нельзя; при развёрнутом окне пропадает ползунок громкости; при смене языка меняются размеры контейнеров; список сегментов растягивается на всю ширину и тратит место.

## Требования
1. **Адаптивный макет.** Окно свободно меняет размер. Минимальный размер скромный (около 760x560). Начальный размер не больше 90% доступной области экрана и вмещается в любой экран от 1280x720. Если окно меньше минимального или экран маленький, появляется прокрутка, а не обрезание. Содержимое никогда не обрезается без возможности добраться до него.
2. **Никаких перекрытий.** Видео, панели и элементы управления не перекрывают друг друга ни при каком размере окна. Виджет видео не зависит от размера кадра исходного видео (даже 4K): у него малый минимальный размер, политика размера «расширяется», и он занимает только отведённое место; остальные панели сохраняют своё место.
3. **Звук всегда виден.** Кнопка Mute и ползунок громкости видны при любом размере окна (от минимального до развёрнутого на весь экран); у ползунка есть минимальная ширина.
4. **Стабильность при смене языка.** Смена языка (en, ru, uk) не меняет размеры и положение контейнеров и кнопок: ширины фиксируются по самой длинной строке среди всех языков (QFontMetrics), длинные тексты сокращаются с многоточием, а не растягивают окно.
5. **Карточки сегментов вместо строк.** Каждый фрагмент это карточка стандартного размера, в которой помещаются все цифры целиком (самая длинная запись, включая часы, при любом масштабе шрифта и экрана; ширина вычисляется по QFontMetrics): номер, начало и конец, длительность, кнопка удаления. Карточки идут слева направо, при нехватке ширины переносятся на следующую строку и так далее (flow-раскладка с переносом, `heightForWidth`). Выбранная карточка подсвечена (цвета обеих тем). Клик по карточке выбирает фрагмент. Область карточек растёт по высоте до разумного предела, затем прокручивается. Кнопки «Добавить фрагмент» и «Удалить» остаются.
6. Стеклянный стиль и обе темы сохраняются.

## Критерии готовности v0.2.1
- Тесты геометрии зелёные: для размеров окна 760x560, 1024x700, 1366x768, 1920x1040, 2560x1400 и режима «развёрнуто», в обеих темах и на трёх языках нет пересечений между панелями и элементами, все элементы управления (включая громкость) видимы и внутри окна или области прокрутки, размеры панелей одинаковы на всех языках при одном размере окна.
- Карточки: при 1, 7 и 25 сегментах нет перекрытий, перенос по строкам работает, цифры не обрезаны.
- Виджет видео не растёт от видео 3840x2160.
- Снимки окна во всех проверенных размерах просмотрены и выглядят аккуратно.

Запасной вариант с клавиатуры: Alt+Влево / Alt+Вправо двигают выбранную карточку.
7. **Нижняя строка** (в один ряд): «Режим» с двумя переключателями «Быстро» и «Точно» (рядом значок-подсказка «?»), широкая полоса прогресса со статусом внутри или рядом, кнопка «Сохранить». Статусная строка отдельным рядом больше не нужна.

Дольше, немного меняется качество и размер файла».

# Версия 0.2.3 — карточки без задвоения и полноэкранное видео (замечания владельца)

## Часть A. Карточки сегментов без задвоения (решение владельца)
Проблема: сейчас ползунок меняет выбранную карточку, а «Добавить» копирует её, поэтому получаются две одинаковые.

Новая логика:
1. **Список карточек в начале пустой.** Автоматической первой карточки на весь файл нет.
2. **Ползунок границ задаёт текущий выбор** («черновик»): после открытия видео это весь файл. Пока ни одна карточка не выбрана, ползунок и поля времени меняют только черновик.
3. **«Добавить»** создаёт НОВУЮ карточку из текущих границ ползунка и сообщает «Фрагмент №N создан». После добавления ни одна карточка не выбрана (режим черновика), ползунок остаётся где был, так что изменения ползунка не затрагивают уже созданные карточки.
4. **Клик по карточке** выбирает её (подсветка), загружает её границы в ползунок и поля, и с этого момента правка ползунка и полей меняет эту карточку (режим правки; в окне видна пометка «Правка фрагмента №N»). Повторный клик по выбранной карточке или клавиша Esc снимает выбор и возвращает режим черновика (ползунок остаётся на текущих значениях, карточка сохраняет свои границы).
5. Крестик на карточке удаляет её (теперь доступен на любой карточке). «Очистить всё» убирает все карточки (подтверждение, если их больше одной), черновик сбрасывается на весь файл.
6. **«Сохранить» неактивна, пока нет карточек** (подсказка объясняет почему). Сохранение, порядок карточек, перетаскивание и Alt+стрелки работают как в v0.2.2.
7. Тексты (en, ru, uk): «Фрагмент №N создан», «Правка фрагмента №N», подсказка неактивной кнопки «Сохранить».

## Часть B. Полноэкранный режим видео
1. **Двойной щелчок по видео** переводит видео в полный экран: безрамочное окно на весь экран (на мониторе, где находится главное окно), видео вписывается с сохранением пропорций и занимает максимально возможную область. **Повторный двойной щелчок** возвращает обычный режим. Также Esc выходит из полного экрана (программа не закрывается), пробел включает и ставит на паузу.
2. Состояние (позиция, пауза/воспроизведение, громкость, mute, границы, карточки) общее для обычного и полноэкранного режимов и сохраняется при входе и выходе. Единый источник данных; виджеты в двух режимах зеркалят друг друга.
3. **Шапка** выезжает, когда мышь поднимается к верхнему краю (около 80 px). В шапке по центру одна кнопка с крестиком «Выйти из полного экрана». Она выходит из полноэкранного режима, но НЕ закрывает программу. Крестик по центру, а не в углу, чтобы двойной щелчок по углу окна не закрыл программу. Больше в шапке ничего нет.
4. **Подвал** выезжает, когда мышь опускается к нижнему краю (около 140 px). Подвал дублирует статичные панели без режима выгрузки и без карточек: Play/Pause, ползунок позиции, время, Mute и громкость (громкость меняется на лету), диапазонный ползунок границ, поля Start/End с кнопками «Начало здесь»/«Конец здесь», кнопка «Добавить». Нет: выбора режима, «Сохранить», карточек, «Очистить всё», языка/темы, «Открыть видео». После «Добавить» на экране появляется уведомление «Фрагмент №N создан» на пару секунд (в полном экране оно обязательно, так как карточек не видно). Предпросмотр по ручкам работает и в полном экране: при перетаскивании ручки показывается кадр этой границы.
5. Панели автоматически прячутся примерно через 1,5 с после ухода мыши или бездействия; курсор прячется при бездействии, когда панелей нет. Появление и скрытие плавные (анимация). Стеклянный стиль и текущая тема.
6. **Техническое требование.** Наложение виджетов поверх нативного QVideoWidget ненадёжно на Windows (панели могут оказаться под видео). Для полного экрана использовать кадры из QVideoSink, нарисованные собственным виджетом (QPainter, вписывание с сохранением пропорций), с обычными дочерними виджетами-панелями поверх; при входе в полноэкранный режим перенаправить вывод плеера на этот виджет, при выходе вернуть обратно на предпросмотр.

## Критерии готовности v0.2.3
- Все тесты зелёные (ядро, консоль, интерфейс, геометрия), реально запущены.
- Тесты логики карточек: пустой список в начале; «Добавить» создаёт новую карточку из границ ползунка и не меняет другие; нет задвоения; режим правки и выход из него (повторный клик, Esc); крестик на любой карточке; «Очистить всё»; «Сохранить» неактивна при пустом списке и активна при наличии; диапазоны, переданные в `trim_each`, соответствуют карточкам.
- Тесты полного экрана (в offscreen экран маленький, проверять логику и геометрию относительно экрана): двойной щелчок входит и выходит; Esc выходит; крестик в шапке по центру выходит и не закрывает окно; шапка и подвал появляются по движению мыши в зонах и скрываются; подвал содержит нужные элементы и не содержит запрещённых; громкость и позиция синхронны; «Добавить» в полном экране создаёт карточку и показывает уведомление; состояние сохраняется при входе и выходе.
- Проверка на реальном ролике: после входа в полноэкранный режим кадры приходят в виджет (QVideoSink), при перетаскивании ручки в подвале приходит кадр нужного момента; после выхода предпросмотр снова получает кадры.
- Снимки полноэкранного окна с видимыми шапкой и подвалом (светлая и тёмная темы, 3 языка по одному) просмотрены.
